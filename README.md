# 🎮 Critical Ops

## 📌 Sobre o projeto

Este projeto individual tem como tema o **Critical Ops**, um jogo de tiro em primeira pessoa (FPS) para dispositivos móveis, conhecido por suas partidas competitivas e estratégicas.

O objetivo do projeto é desenvolver uma aplicação relacionada ao universo do jogo, explorando suas características, funcionalidades e elementos que fazem parte da experiência dos jogadores.

## 🎯 Objetivo

Desenvolver um projeto individual que permita aplicar os conhecimentos adquiridos durante o curso, utilizando o Critical Ops como tema principal.

## 🕹️ Sobre o Critical Ops

Critical Ops é um jogo FPS competitivo no qual os jogadores participam de partidas em equipes, utilizando estratégias, habilidades e trabalho em conjunto para alcançar a vitória.
